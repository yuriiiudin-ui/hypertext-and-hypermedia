Основи Docker та контейнеризації

Docker змінив те, як ми доставляємо програмне забезпечення. Замість того, щоб налаштовувати середовище на кожному сервері, ми пакуємо наш додаток у контейнер.

Приклад простого Dockerfile


FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "app.py"]

  • Офіційна документація Docker
  • Kubernetes для початківців
